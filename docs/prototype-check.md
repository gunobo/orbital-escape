# 7. 프로토타입 실행 후 점검 (기획서 7번 칸에 옮겨 적을 내용)

> 학번 1411 임제민 · 게임 제목: 궤도이탈
> 점검 기준: 기획서의 3번 "과학 개념 → 게임 메커니즘 변환표"와 5번 "배우게 되는 것"

## 실행 결과

게임을 실행해서 우주선을 날리며 확인한 내용이다.

- 중력장 근처로 가면 우주선이 끌려가고, 한가운데의 고리를 통과하면 초록색, 놓치면 빨간색이 된다. 놓치면 목숨(❤️ 3개)이 하나씩 줄고 0이 되거나 운석에 부딪히면 게임이 끝난다. 점수는 이동 거리(m)이고 랭킹 서버에 올라간다.
- 기름을 먹으면 연료가 차고 우주선이 무거워져서, 같은 힘으로 움직여도 가속이 둔해진다.
- 시작 전에 운석의 수직·수평 속도를 따로 정할 수 있고, 두 운석(떨어뜨린 것 / 던진 것)이 같은 시각에 같은 높이에 있는 비교 실험이 화면에 나온다.
- 게임 중 물리 패널에서 F = GMm/r² 그래프, 작용-반작용 힘, 에너지를 실시간 숫자로 볼 수 있고, 판이 끝나면 이번 판 숫자로 만든 복습 퀴즈가 나온다.

## 수정이 필요하다면 무엇을?

처음 만든 프로토타입에서 아래 4가지가 과학적으로 맞지 않아서 고쳤다.

| # | 처음 프로토타입의 문제 | 왜 과학적으로 틀렸나 | 어떻게 고쳤나 | 확인 방법 |
|---|---|---|---|---|
| 1 | 운석이 **일정한 속도**로 떨어졌다 | 자유낙하는 중력 때문에 속도가 일정하게 *증가*하는 **등가속도 운동**이다. 수평으로 던진 물체는 수평은 등속, 수직은 등가속도이고 두 운동은 **독립**이다 (기획서 3번 표의 3번째 줄) | 운석에 낙하 가속도 g를 적용하고(게임 스케일로 달 표면 중력 1.62 m/s² 사용), 수평은 등속으로 분리. 시작 화면에 두 운석의 위치를 0.5초마다 찍은 비교 실험을 추가 | 자동 테스트: 수직 속도 v = g·t, 떨어뜨린 것과 던진 것이 같은 시각에 같은 높이 |
| 2 | 중력장의 **고리를 지나면 중력이 갑자기 사라졌다** | 실제 중력은 지나간 뒤에도 계속 당긴다. 사라지게 하면 가까워질 때 얻은 운동에너지를 돌려주지 못해 **에너지 보존**이 깨진다 | 영향 반경 안에 있는 동안은 지난 뒤에도 계속 당기게 하고, 위치에너지를 정의해서 운동에너지 + 위치에너지가 보존되는지 확인 | 자동 테스트: 힘을 안 주고 중력장을 지나가는 동안 역학적 에너지 E의 변화가 운동에너지의 2% 미만 |
| 3 | 기름을 먹으면 **질량이 늘기만** 했고, 연료를 태워도 안 가벼워졌다 | 로켓의 질량은 연료 질량을 포함하므로, 연료를 태우면 가벼워지고 기름을 먹으면 무거워진다 (F = ma에서 같은 힘이면 질량이 클수록 a가 작다) | 질량 = 우주선 본체 + 연료. 연료량에서 질량이 바로 계산되게 했다 | 자동 테스트: 시간이 지나 연료가 줄면 질량도 줄고, 기름을 먹으면 늘어난다 |
| 4 | 옆으로 움직이다가 키를 떼면 **공짜로 감속**됐다 | 우주에는 공기 저항이 없어서, 힘이 없으면 속도가 그대로 유지된다 (관성, 뉴턴 제1법칙). 감속하려면 반대 방향으로 엔진을 써야 한다 | 감속을 "관성 제어 장치"로 바꾸고 줄어든 운동에너지만큼 **연료를 쓰게** 했다 (에너지 손실 = 열·배기로 전환). Z키로 끄면 관성 그대로 미끄러지고 에너지가 보존된다 | 자동 테스트: 끄면 속도 유지, 켜면 운동에너지가 줄고 연료도 줄어든다 |

### 처음부터 맞았던 것 (그대로 유지)

- **중력 가속도는 낙하하는 물체의 질량과 무관**하다 (a = GM/r², 갈릴레오 / 등가원리). 우주선이 무거워지면 중력(힘)은 커지지만 가속도는 같다. 대신 엔진의 가속도(a = F/m)가 작아져서 조작이 둔해진다.
- 거리가 2배가 되면 중력은 1/4이 된다 (역제곱). 질량이 2배면 중력도 2배다.
- 작용-반작용: 내가 행성을 당기는 힘 = 행성이 나를 당기는 힘 (크기 같고 방향 반대). 가속도는 질량에 반비례해서 가벼운 우주선이 훨씬 많이 끌려간다.

### 아직 현실과 다른 점 (게임이라서 단순화한 것)

- 실제 만유인력 상수 G는 너무 작아서 G와 행성 질량을 묶은 값(μ = GM)을 게임 크기에 맞게 키워 썼다. 공식의 모양(1/r²)은 그대로다.
- 중력장 한가운데(r < 5 m)에서는 힘이 무한대로 커지지 않게 일정하게 두었고, 영향 반경(26 m) 밖에서는 중력을 0으로 잘랐다.
- 행성은 가만히 있는 것으로 처리했다 (반작용으로 움직이는 정도는 숫자로만 보여 준다: 질량비가 약 1 : 40,000이라 가속도가 거의 0이다).
- 중력장 밖에서는 "순항 장치"가 진행 속도를 자동으로 맞춘다 (현실에서는 힘이 없으면 속도가 유지될 뿐이다).

